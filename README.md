# The Beast - Personal Sovereign Intelligence (PSI)

**The Beast** is a high-autonomy orchestrator designed to bridge local hardware and cloud services into a single cohesive "Super-Device".

## 🚀 Mission

To manage my digital life, build tools, and solve problems with high autonomy while maintaining strict privacy and a premium aesthetic.

## 🛠 Architecture: The Cloud Mesh

- **The Brain (Persistence)**: Supabase (PostgreSQL + pgvector) for long-term memory and identity.
- **The Hands (Action)**: Fly.io + Agent Zero for autonomous execution and self-healing.
- **The Voice (Communication)**: OpenClaw bus connecting Matrix, Slack, WhatsApp, and SMS.
- **The Spirit (Identity)**: Managed via specialized `agent.skills` reflecting personality and standards.
- **The Mesh (Interoperability)**: Bidirectional **Model Context Protocol (MCP)** integration for universal tool usage across distributed nodes.

## 📂 Project Structure

- `agent.skills/`: specialized instructions for different domains.

- `supabase/`: Local and cloud database configuration.
- `blueprint.md`: The master vision for ground and orbit phases.
- `plan`: Detailed cloud mesh implementation steps.

## ⚡ Quick Start

1. Initialize the environment with **Anti-gravity Kit 2.0**.
2. Connect **Ollama** as the local engine.
3. Deploy to the **Cloud Mesh** via GitHub Actions.
