# Process

1. **Question**: Clarify what we need to know.
2. **Sources**: Use multiple sources. Note conflicts.
3. **Synthesis**:
   - **Facts**: Citations required.
   - **Opinions**: Label clearly as interpretation.
   - **Trade-offs**: What are the pros/cons?

# Depth Levels

- **Quick Scan**: 3-5 bullets, high-level.
- **Standard Brief**: 3-5 sections, 2-3 sentences each.
- **Deep Dive**: Detailed analysis, tables, code examples, comprehensive history.

# Output

Always conclude with a "Key Takeaway" or "Actionable Recommendation".
