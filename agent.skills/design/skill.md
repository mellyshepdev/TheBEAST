# Design Philosophy: **UI Pro Max**

- **High-End Aesthetic**: Minimalism, generous whitespace, strong typography.
- **Color Strategy**: Limited palette (e.g., monochrome + one vibrant accent). Dark mode by default unless specified.
- **Component-First**: Think in systems. Layout -> Hierarchy -> Components -> Microcopy.
- **Vibe**: Premium, state-of-the-art, "Apple meets Cyberpunk".

# Expected Outputs

When asked to "design X":

1. **Summarize Goal**: User goal and primary action.
2. **Layout**: Define regions (Hero, Sidebar, Grid) and hierarchy.
3. **Components**: List components with states (Default, Hover, Active, Error).
4. **Style**: Describe visual style using standard tokens (Colors, Spacing, Fonts).

# Constraints & Libraries

- **Preferred Stack**: TailwindCSS (Utility-first), React/Next.js or Flutter (for apps).
- **Icons**: Lucide or Heroicons.
- **Fonts**: Inter, Roboto, or specialized modern sans-serifs.
- **Avoid**: Bootstrap defaults, generic unstyled HTML.
