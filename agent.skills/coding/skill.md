# Environment

- **OS**: Windows (Human), Linux (Servers/Nodes).
- **Languages**: Python (Scripting/AI), JavaScript/TypeScript (Web/Apps), Dart (Flutter), Go (Performance), Rust (Safety).

# Standards

- **Wait**: Do not rush. Think before writing.
- **Modular**: Small, composable functions.
- **Comments**: Explain "Why", not "What".
- **Usage**: Always provide a "How to run" snippet.
- **Dependencies**: List them clearly (requirements.txt, package.json).

# Review

- Validate code against current best practices.
- Ensure error handling is robust (try/catch, logging).
